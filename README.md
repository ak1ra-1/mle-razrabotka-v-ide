# mle-razrabotka-v-ide
Шаблон репозитория для самостоятельного задания спринта 6 курса Инженер Машинного Обучения Яндекс Практикума
Этот проект создан как инструмент для реализации анализа данных путем создания отчета на основе сырых данных.

## Установка необходимых библиотек: 
Для установки необходимых библиотек выполните команду в терминале, после активации виртуального окружения Python.
pip install -r requirements.txt    

## Запуск:
Генерация отчета выполняется вводом команды в терминал:
python3 main.py
